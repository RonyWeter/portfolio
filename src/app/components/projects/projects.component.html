Full-Stack Application
Bank KYC System

A comprehensive yet user-friendly system designed for banks to onboard customers efficiently. This platform enables users to create bank accounts by submitting their personal information securely online. Customers can upload identification documents like IDs or passports, provide a live selfie for facial verification, and submit an image of their signature to complete the process. Built with a strong emphasis on security, compliance, and seamless user experience, this system streamlines customer verification while ensuring data accuracy and regulatory adherence.

A secure and user-friendly online KYC system that enables customers to open bank accounts remotely. The platform allows users to fill in personal information, upload identification documents (ID or passport), and capture a live selfie for identity verification. Additionally, users can upload an image of their signature to complete the verification process. Built with a focus on security, smooth user experience, and efficient data processing for banking compliance.

Full-Stack Application
Car Listing Platform

A user-friendly and efficient web platform that allows clients to add and manage cars for sale. Clients can upload a main image, multiple sub-images, and detailed specifications for each car—such as model, year, condition, mileage, engine type, and more. Once added, users can browse a well-organized list of cars, each displayed with its images and key details. The system is built with a focus on simplicity, speed, and scalability, offering a smooth experience for both car owners and potential buyers.
